# Community, guilds and VSM

[Documentation entry point](../README.md) · [Architecture](architecture.md)

The guild is a provisional description of human infrastructure: people who help each other learn, identify expertise, collaborate and find work. Membership need not be tied to a single occupation.

Stafford Beer’s Viable System Model (VSM) supplies a possible vocabulary for balancing autonomy and coordination. The mapping below is our working application, not a validated governance design or a substitute for studying the model.

| VSM function | Possible community expression | Question to resolve |
| --- | --- | --- |
| System 1: operations | Producers, workshops and working groups | What decisions belong to each autonomous unit? |
| System 2: coordination | Scheduling, interfaces and shared conventions | How do we prevent clashes without directing everyone? |
| System 3: internal management | Infrastructure allocation and resource agreements | What authority is actually delegated, and by whom? |
| System 3*: audit | Direct checks on access, accounts and working conditions | How can practice be checked beyond routine reporting? |
| System 4: adaptation | Research into needs, markets, technology and threats | Who tests assumptions and prepares for change? |
| System 5: policy and identity | Shared purpose, constitutional rules and boundaries | How are priorities set and power challenged? |

VSM is recursive: a workshop may need these functions internally while also being an operational unit of a wider network. It should not be interpreted as five committees stacked above every participant.

## Governance work still needed

A network can become bureaucratic or develop informal power concentrated around founders and experts. Keeping administration small does not by itself make governance democratic.

We need to investigate membership rights, transparent delegation, dispute resolution, privacy, compensation, asset stewardship and exit. A founding group should be able to say clearly what it can decide, what it cannot decide and how others can replace it.

The detailed VSM reading list remains to be curated. For now, the historical influence is recorded in [provenance](provenance.md), and this table should be treated as a discussion aid.
