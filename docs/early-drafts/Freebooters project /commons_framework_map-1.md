# Commons Framework: Elements, Interactions, Risks, Evidence

## 1. Core Components

- Technology Base: AI tools, fab/manufacturing (3D printers, CNC, routers), micro-growing, micro-energy grids.<br>- Social Practices: Sociocracy, Agile, Value-chain mapping.<br>- Existing Models: Project Kamp, Precious Plastic.<br>- Class Dynamics: Neo-artisans/smallholders, precarious professionals, potential corporate co-option.<br>- External Pressures: Corporations, state policy/regulation, global supply chains, climate stress.

## 2. Interactions Matrix

| From → To | Interaction | Risks | Evidence / Notes |
| --- | --- | --- | --- |
| AI → Neo-artisans | Lowers technical barriers; enables creativity without deep STEM skills | Dependency on proprietary AI; skill atrophy | AI used for prototyping, design (e.g. CAD assistants); open-source AI projects exist |
| AI → Fab/Manufacturing | Generative design, error detection, automated workflows | Over-reliance on closed ecosystems; hardware bottlenecks | Industry CAD + generative design already in use |
| AI → Social Practices | Enhances decision-support (dashboards, knowledge commons) | Risk of AI bias shaping governance | Early experiments in AI-assisted deliberation |
| Fab/manufacture → Value chains | Local recycling, production loops | Dependence on raw materials, filament imports | Precious Plastic machines; local recycling hubs |
| Micro-growing → Value chains | Food loops, waste→compost→food | Energy + water intensity; scale limits | Urban farming pilots, hydroponic startups |
| Sociocracy → Governance of commons | Prevents concentration, fosters autonomy | Adoption fatigue, slow uptake in crises | Documented in co-ops, NGOs |
| Agile → Commons production | Enables iterative innovation, fast pivots | Burnout, clash with consensus cultures | Agile common in tech/startups; less in physical production |
| Value-chain mapping → External pressures | Reveals choke points, supports resilience | Mapping w/o action; complexity overwhelm | Used in food sovereignty & supply resilience research |
| Project Kamp → Commons model | Off-grid living lab, prototyping land systems | Fragility, founder dependence | Documented on YouTube, One Army site |
| Precious Plastic → Commons model | Distributed plastic recycling | Economic fragility of hubs; variable uptake | 400+ global hubs, open source docs |
| External pressures → Commons nodes | Corporate/platform encroachment | Capture, dependency, IP lock-in | Cases of Uber, Amazon disrupting local economies |
| Climate stress → Commons nodes | Push toward resilience, self-sufficiency | Resource scarcity, shocks overwhelm systems | Precedents in disaster resilience studies |


## 3. Key Evaluation Questions

- Evidence: What real-world data exists for each interaction? (Docs, case studies, experiments)<br>- Risks: What are the likely failure modes? (e.g. sociocracy adoption collapse, agile burnout)<br>- Feedback Loops: Do failures get noticed and corrected, or accumulate silently?<br>- Metrics: How can we measure success? (autonomy, dependency reduction, resilience under stress)
